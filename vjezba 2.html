4. zadatak

Web programiranje

Web programiranje je proces stvaranja i održavanja web stranica i web aplikacija.

HTML

HTML (HyperText Markup Language) je standardni jezik za stvaranje web stranica.

Osnovni elementi

Osnovni elementi HTML-a su tagovi koji se koriste za strukturiranje sadržaja web stranica.

Tekst

Tekst je osnovni element web stranica.

Odlomci

Odlomci su grupe teksta koje su odvojene linijama.

Prijelomi redaka

Prijelomi redaka se koriste za prelazak na sljedeći redak u web stranici.
